# Sound Notes — Vinyl LP Recording and Sound Engineering

A single-page, self-contained reference memo on how vinyl LPs are recorded,
cut, pressed and played back — and how the medium's physical constraints
shape the engineering decisions behind a good-sounding record.

The document lives in
[`vinyl_lp_recording_sound_engineering_memo_v3.html`](./vinyl_lp_recording_sound_engineering_memo_v3.html),
an accessible, tabbed long-form memo with embedded figures and an
interactive RIAA-equalization demonstration.

## Contents

The memo is organised into eight navigable sections:

1. **Overview** — the journey from master to mould; cutting the lacquer,
   electroforming, pressing.
2. **Groove & stereo** — the 45/45 stereo system; lateral vs. vertical
   modulation; why deep bass is centred.
3. **Speed & sequencing** — linear groove velocity, the inner-groove
   problem, and how track order interacts with sound quality.
4. **Bass, treble & dynamics** — loudness as groove width; the noise
   floor; managing transients across each side.
5. **RIAA equalization** — the complementary record/playback curve,
   with an interactive frequency slider and waveform visualisation.
6. **Playback limitations** — wow & flutter, tracing/inner-groove
   distortion, surface noise, crosstalk, tonearm and cartridge setup.
7. **Engineering craft** — how vinyl's constraints can encourage a more
   coherently mastered record; "mastering by constraint".
8. **Summary** — consolidated reference table of issues, causes,
   responses and experiential benefits.

## Assets

## Viewing

Open the HTML file directly in any modern browser:

```bash
open vinyl_lp_recording_sound_engineering_memo_v3.html
```

The page loads Google Fonts (Source Sans 3 / Source Serif 4) from a CDN;
an active internet connection is required for the intended typography,
though all content remains readable offline.
